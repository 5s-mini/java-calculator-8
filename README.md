# java-calculator-precourse

---

## 1. 기본 조건

### 입력 조건

- [x] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

### 문자열 입력

- [x] 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.
- [x] 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다.
    - [x] 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.

### 덧셈 결과

- [x] 구분자를 기준으로 분리한 각 숫자의 합을 결과로 출력한다.

## 2. 프로그램 동작 조건

- [x] 문자열은 구분자와 양수로 구성되어야 한다.

## 3. 출력 조건

- [x] 올바른 덧셈 결과를 출력한다.

## 4. 테스트 코드 작성

### 입력 테스트

- [x] 문자열 입력 테스트
    - [x] 공백 예외 처리
    - [x] null 예외 처리
    - [x] 숫자가 존재하지 않을 시 예외 처리
    - [x] 음수 예외 처리
    - [x] 기본 구분자를 가지지 않을 경우 예외 처리
    - [x] 커스텀 구분자를 가지지 않을 경우 예외 처리

### 출력 테스트

- [x] 덧셈 결과 출력 테스트
    - [x] 기본 구분자를 가지는 문자열의 덧셈 결과 출력
    - [x] 커스텀 구분자를 가지는 문자열의 덧셈 결과 출력
